# 22차 실행 계획 — 공개 안정화와 전체 수락

기준 main `bae8599`, 2026-10-26. **설계 제안이며 실행 승인·구현 완료가 아니다.** 21차는 보류한다. 제품·공개 DB·runtime 변경과 시험 실행은 하지 않았다. [진단서](../work-orders/reports/CX-44.md), [추천 설계](REDESIGN_PROPOSAL.md)를 함께 읽는다.

## 단계별 실행 계획: 공개 안정화 우선

이하 각 단계는 계획 승인 뒤 별도 작업지시로 구현한다. 단위는 '구현+독립 검토+필요 회귀를 묶은 차수'이며 날짜/보장 일정이 아니다. UI는 Claude 소유: 요구사항/계약을 전달하고 UI 파일은 Claude가 변경한다. 전체 안정화는 **5–7차**, 전체기획 수락은 **추가4–6차, 누적9–13차** 작업량 추정이다. 데이터 이관/보장 변경·공개 조작·장기시험 승인은 시간 추정과 별개 선행조건이며 막히면 완료를 약속하지 않는다.

## 기획 전체 완성 경로

공개 안정화 뒤 추가4–6차 예상: (1) A 영역 미완료 F/T 항목과 통신/결과불명 알람·과거복구알람/epoch 등 완결, (2) 취소/명령경합/이력·권한·운영자동화 남은 요구 통합, (3) backup_set_id 일치하는 두SQLite+PG 복원/새설치/인증서교체·재시작 현장절차, (4) T01–T12 동일release 묶음·성능/48태그/10명/8시간의 공식 수락 및실패보완. A 영역 결과에 따라 기능범위가늘면재산정한다. 24시간관찰이 원래8시간부하/장비조건과다르면 자동대체하지않는다. 사용자승인이없어8시간시험을하지못하면 '전체수락미완료'로남긴다.

## 기존 공개 데이터 처리와 되돌리기

1. 구현 승인 후, 공개적용 전에 scope/DB migration head·권한·미확정명령·execution·source/stream·프로세스소유자와 백업위치를 manifest로 남긴다. 백업은 접근제한·암호화·checksum을 갖춘 기존소유스토리지에 둔다. 무료외부대용량저장소가있다고가정하지않는다.
2. 이미증거가사라진데이터는되살렸다고표현하지않는다. legacy execution은 '원본없음/시간불명/검산가능수량'을분리봉인하고 원래ID·해시·미해결gap/실패기록을유지한다. 재정산해UNKNOWN을정상값으로바꾸지않는다.
3. 새summary/구간자료는 기존결과와 비교 후 version표시한다. 미확정/활성실행·알람·명령을정리에서보호한다. 보전이확인된기간/테이블만bounded삭제하며 공개삭제는exact목록과승인범위안에서만한다. pin으로예산초과면새작업을명시차단하고정상처럼돌리지않는다.
4. rollback은 삭제전에는 이전앱/설정+신규쓰기중단으로가능하도록expand→비교→switch→contract를분리한다. 삭제후에는앱downgrade만으로원본이복구되지않는다. 검증된공통backup_set으로복원하거나새모델을계속읽는전진수정이필요하다.
5. SQLite만옛시점으로돌리고PG는최신으로두거나, 이전runtime복사본을동시기동하지않는다. 복원시새owner절차/identity·cursor·idempotency·수량·미확정명령대조후재개하며 새ID로자동실행하지않는다. 원본소실후복원불가시점/백업보존기간/허용RPO는공개변경승인전에명시한다.

## 차수 추정의 조건과 기획 기준

공개 안정화 5~7차, 전체 수락 누적 9~13차는 범위와 운영 호스트가 확정된 뒤의 작업량 추정이다. 무료 B 프로필의 24시간/30일/7일 보관은 원래 기획의 7일/90일/180일과 다르다. 원기획 전체 완성을 원하면 그 기간을 만족하는 저장소·조회·복원 용량을 확보하고 C의 보관 계층을 구현해야 하며, 이 경우 추가 약2차(누적11~15차)를 계획한다. B로 기준을 바꾸는 명시 승인이 있으면 9~13차는 **승인된 개정 기획**의 전체 수락이며 원기획 충족으로 보고하지 않는다. 무료 저장소가 확보되지 않으면 C 경로는 차단이고 완료 차수는 확정할 수 없다. 보관 정책이 승인되지 않으면 현재 원기획을 유지하며 B 구현에 착수하지 않는다.

DB 실측이 차단된 현재 상태에서 R0는 공개 표별 bytes/정확 행 수/두 시점 증가율을 먼저 확보해야 한다. 24시간 관찰과 원기획 8시간 시험은 둘 다 이번에 실행하지 않으며 기존 제외 지시를 우회하지 않는다. 관찰 승인이 없으면 기능 수락만 완료할 수 있고 장기 안정화·전체 수락은 보류한다.
