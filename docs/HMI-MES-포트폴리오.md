## 촬영과 검증 범위

- 2026-10-29 공개 배포(hmi-mes.vercel.app)에서 설비 전원을 켜고 실제로 운전하며 촬영했습니다. 모의 데이터나 고정 데이터 미리보기는 쓰지 않았습니다.
- 운전 내용:
  - 새 작업지시 WO-20261029-001(목표 8) 등록·배포 → 불러오기 → 예열 → 생산 → 일시정지·재개 → 종료 → 정산(양품 8 · 불량 0)
  - 기존 작업지시 WO-20261028-002 3회째 실행 → 정산(양품 40 · 불량 1)
  - 공압 5.5 bar를 넣은 공정 설정 RCP-T1 v2 등록 → 작업지시 WO-20261029-002(목표 30) → 운전 중 속도 11 · 온도 155 · 공압 5.8 변경 → 종료 → 정산(양품 30 · 불량 1)
- 촬영 중 설정 변경 1건과 종료 1건은 응답을 확인하지 못해 **결과 불명**으로 남았습니다. 설비 수집값과 정산으로 실제 반영은 확인했지만, 화면은 해당 요청을 성공으로 바꾸지 않았습니다. 응답이 끊긴 원인은 조사하지 않았습니다.
- SPC 관리한계는 실행 처음 20분으로 계산합니다. 이번 실행은 몇 분짜리라 관리도가 계산되지 않았고, 그 화면을 그대로 실었습니다.
- 대시보드의 가동 비율이 낮은 것은 하루 중 설비가 꺼져 있던 시간을 ‘불명’으로 둔 결과입니다.
- 시험 수치(Python 2,354개 등)는 2026-10-23 전체 로컬 검사 기준입니다. 10-24 이후 변경은 변경 범위 시험만 실행했습니다.
- 공개 배포의 알람 생성 미연결, 30분 단절 복구 실패 등 남은 기준은 12쪽에 그대로 적었습니다.

화면 원본은 [docs/assets/portfolio](assets/portfolio), 레이아웃 검사 결과는 [pdf-validation.json](assets/portfolio/pdf-validation.json)에 있습니다.

## 다시 만들기

문구와 배치의 원본은 [scripts/build-portfolio.mjs](../scripts/build-portfolio.mjs)와 [scripts/portfolio.css](../scripts/portfolio.css)입니다. 이미지는 HTML 안에 포함되어 별도 파일 없이 열립니다.

```sh
node scripts/build-portfolio.mjs
```

- Playwright와 Chromium, 한글 글꼴 Noto Sans KR이 필요합니다.
- Chromium 경로는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정할 수 있습니다.
- 생성 과정은 앱·DB·외부 AI에 요청하지 않습니다.
- 각 쪽의 내용이 하단을 넘거나 이미지가 비면 PDF를 만들지 않고 실패합니다.
- 코드 발췌는 작업 파일이 아니라 고정 커밋 `59a1064`에서 직접 읽습니다.
