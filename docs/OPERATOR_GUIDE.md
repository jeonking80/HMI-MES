# 가상 포장라인 사용 순서

운영 화면: <https://hmi-mes.vercel.app>. `demo` 계정과 직접 변경한 비밀번호를 사용한다. 처음에는 **설비 운영**에서 라인이 보이고 값이 갱신되는지 확인한다. `등록된 수집원이 없습니다`나 통신 불명 상태에서는 설비 연결 준비가 끝난 것이 아니다.

## 1. 생산 조건과 작업 만들기

**작업지시 · 공정 설정** 탭을 연다. 처음 시험할 때는 다음과 같이 등록할 수 있다. ID는 기존 것과 겹치지 않게 지정한다.

| 새 공정 설정 항목 | 예시 |
| --- | --- |
| 설정 ID | `recipe-001-v1` |
| 설정 그룹 ID | `recipe-001` |
| 버전 | `v1` |
| 품목 ID | `item-001` |
| 설정 온도 | 150 ℃ |
| 설정 속도 | 10 m/min |

설정을 등록한 뒤 **작업지시 작성**에서 해당 설정과 포장라인을 선택한다. 작업지시 ID(예: `work-001`), 목표 양품 수량(예: 20개), 생산 예정일을 입력하고 **작성 중 작업지시 등록**을 누른다.

## 2. 작업을 설비에 연결하기

1. 목록의 **작업지시 배포** → 내용을 확인하고 **작업지시 배포 요청**을 누른다.
2. 배포 결과가 확정되면 아래 **배포 기록 확인 · 다음 업무 준비**를 누르고 작업 목록을 새로 조회한다.
3. 해당 작업의 **실행 연결 준비**를 누르면 설비 운영 탭으로 이동한다.
4. 라인과 작업 내용을 확인하고 **실행 연결 내용 확인** → **실행 연결 · 작업 불러오기 요청**을 누른다.
5. 작업 불러오기 결과 `SUCCEEDED`와 설비의 현재 작업을 확인한다. 접수됐다는 응답만으로 연결 완료를 판단하지 않는다. 확인이 늦으면 **원래 작업 불러오기 결과 조회**를 사용한다.

## 3. 생산·일시정지·종료

설비가 실제로 예열하여 준비 상태가 될 때까지 기다린다. 시작에는 REMOTE/AUTO, 닫힌 가드, 비상정지 해제, 고장 없음과 설비 준비 조건이 필요하다. 조건을 충족하면 **시작**을 누르고 실행 결과와 운전 상태·생산 수량을 확인한다.

한 명령의 확정 결과를 확인한 뒤 **확정 결과 확인 · 다음 요청 준비**를 눌러 다음 명령으로 진행한다. **일시정지**는 운전을 멈추고, **정상 종료**는 확인 절차 후 잔류 제품을 정리하고 작업을 종료한다. 통신 응답을 받지 못했으면 원래 ID의 결과를 조회한다.

목표 수량을 입력한 것만으로 자동 종료되는 것으로 가정하지 않는다. 현재 구현의 작업 종료는 사용자의 명시적 정상 종료 요청을 기준으로 확인한다.

## 4. 실적 대조와 다음 작업

**작업지시 요청 기록**의 **원래 실행 기록 조회**에서 종료된 실행을 조회한다. 설비 원본 최종 수량과 저장 실적 대조가 `SETTLED`인지 확인한다. 양품·불량·폐기·재공 수량을 확인하고 **저장 정산 재확인 후 기록 보관**으로 정리한 뒤 다음 작업을 준비한다.

접수, 명령 실행 성공, 설비 종료, 최종 실적 대조는 각각 별도 단계다. 값이 오래됐거나 불명일 때는 정상 상태로 간주하지 않는다.

## 연결이 보이지 않을 때

**수집원 다시 조회**를 누른다. 여전히 없으면 관리자가 [설비 연결 준비](../deploy/plant-hosting.md)를 적용해야 한다. 화면의 **작업지시 요청 기록**·**취소 기록**은 이전 요청의 결과를 복구하는 보조 조회이며 설비를 연결하는 입력란이 아니다.
