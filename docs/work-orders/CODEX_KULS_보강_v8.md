## 1. 정정과 근거 (Claude, 2026-10-24)

7차 지시서 §2-2의 "시작 직후 일시 지연" 결론은 **틀렸다.** 철회한다. 공개 DB의 3차 시도 구간(08:13:05~08:14:42Z, 100건)에서 `Line.State` 수집 → 저장 지연(ms)은 다음과 같다.

```
2700 4852 … 397 440 … 453 2009 4510 4223 3805 5800 5420 … 1100 736 2856 … 179 369 436
```

지연은 시작 직후뿐 아니라 **운전 중에도 3초 단위의 정체·적체가 반복**됐다. Codex가 기록한 수집 `METADATA_FULL` 88회와 맞는다. 화면의 3초 최신성 조건은 이 정체를 정상적으로 막고 있다. UI 조건은 바꾸지 않는다.

핵심은 **원장이 운전 시간에 비례해 무한히 커진다**는 점이다. 6차 사본 실측 기준:

| 항목 | 값 | 1건당 |
|---|---:|---:|
| `batch_ledger` | 4,267행 / 4,335,235B | 약 1.0KB |
| `missing_ranges` | 453행 / 5,664,074B | 약 12.5KB |
| 한도 `max_metadata_bytes` | 10,000,000B | — |

1Hz 수집이면 원장은 시간당 약 3.6MB 늘어난다. 압축해도 비율만 줄 뿐이다. 이대로라면 **고정 한도를 가진 게이트웨이는 누적 몇 시간 운전 뒤 반드시 멈춘다.** 압축 호출 위치를 `enqueue` 쪽에 추가하는 것만으로는 해결되지 않는다.

## 2. 할 일

1. **사본 확인(읽기 전용 1회).** 운영 SQLite를 백업 API로 복사한 사본만 연다. 다음 값을 기록한다.
   - 표별 행 수와 `sum(metadata_bytes)`
   - `outbound_batches`의 상태별 건수
   - ACK TEXT/BLOB별 건수·크기, 남은 미압축 확정 ACK의 회수 가능량
   - `missing_ranges` 1행의 필드별 크기. 무엇이 12.5KB를 차지하는지 확인한다.
   - 연속된 `missing_ranges`가 몇 개의 구간으로 합쳐지는지
2. **설계 결정(high 검토).** 원장을 **고정 크기**로 유지하는 방법을 정해 `reports/CX-27.md`에 남긴다. 기준 문서 변경이 필요하면 변경 이유와 영향을 함께 기록한다.
   - **확정 원장 접기:** 서버가 확정(`verified_through_seq`)했고 ACK가 서버에 영속된 구간은 게이트웨이 원장에서 체크포인트 1행으로 접는다. 체크포인트에는 generation, 마지막 seq, 누적 해시를 둔다. 체크포인트 이하 seq의 재등록은 규칙으로 거절해 batch ID 충돌 검사를 대신한다. 개별 영수증 원본은 서버 `ingest_batches`에 이미 있다.
   - **유실 근거 압축 표현:** 연속된 `missing_ranges`는 내용 손실 없이 하나의 구간으로 합친다(시작·끝 seq, 개수, 해시 목록 또는 누적 해시). 유실 사실과 범위는 지우지 않는다.
   - 위 두 방법이 기존 불변 조건(원래 execution_id 귀속, 중복 제거·커서 원자 저장, 불명의 정상 대체 금지)을 해치면 채택하지 말고 이유를 적는다.
3. **구현과 시험.** 채택한 방법을 구현한다. 시험은 아래 두 개를 추가한다.
   - **장기 용량 시험:** 1Hz 기준 24시간 분량(86,400배치)을 가속 적재해도 메타데이터가 한도 아래에서 일정하게 유지되고, `METADATA_FULL`이 나지 않는다.
   - **안전 시험:** 체크포인트 이하 재등록 거절, 유실 구간 보존, 접기 중 오류 시 원자적 롤백.
   - 실행은 관련 단위 시험 1회, Ruff 1회로 끝낸다.
4. **운영 적용.** 기존 운영 SQLite에 새 표현을 적용하는 일회성 이관을 사본에서 먼저 1회 검증한다. 그다음 사용자 승인을 받아 원본에 1회 적용한다. 새 source·generation은 만들지 않는다.
5. **실연 1회.** 7차 지시서 §2-1의 클릭 순서와 §2-2의 대기 조치로 10분 생산 실연을 1회 한다. 실패하면 사유와 함께 멈춘다.
