## 검증 근거와 범위

- 실제 PostgreSQL/ASGI에서 viewer의 기존 대시보드 GET과 증명 배열을 확인했다. 새 알람 도구는 실제 활성/복귀 미확인 알람을 구분하고, 미지원 설비404를 null로 남기며 알람 인스턴스·조치 기록을 변경하지 않았다.
- 실제 전용 게스트 세션을 새로 발급하며 요청해도 세 번째 요청은429이며, 앞선 두 요청만 mock 공급자에 전달되었다.
- 단위 시험은 전체 시한이 여러 모델 왕복에 걸쳐 누적되고 인증·내부 GET도 포함함을 확인했다. 공급자 HTTP 타임아웃도 동일504 코드로 구분한다. 설정의 NaN/Infinity/비정수·범위 위반과 URL 자격 증명·쿼리를 거절한다.
- caplog의 성공·공급자 오류·시간 초과·내부 도구 오류 경로에서 테스트 프롬프트·답변·키가 기록되지 않음을 확인했다. 실제 비밀값을 사용하지 않았다.
- 전체 프로젝트 회귀·운영 브라우저 검사는 이 작업에서 실행하지 않았으며 통과로 주장하지 않는다. 모델은 모두 mock 응답이고 실제 Nemotron 네트워크 호출은 없었다.
