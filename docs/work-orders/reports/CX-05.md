# CX-05 결과

- 커밋: 통합 검증 후 이 보고서에 기록한다.
- 상태: 개별 PostgreSQL·ASGI 검증 통과, 전체 통합 검증 진행 중.
- 변경 파일: `apps/api/dashboard.py`, `apps/api/dashboard_http.py`, `tests/integration/test_dashboard.py`, `docs/architecture/DASHBOARD.md`. 공통 경로 등록은 별도 통합 커밋에 포함한다.
- 계약 차이: 없음. 심각도 키는 고정 enum을 만들지 않고 원래 규칙 값을 사용한다.
- 실행한 검증: 실제 PostgreSQL·ASGI `test_dashboard.py` 4개 통과(8.24초). 미관측/정상/지연, 현재 실행, 다른 수집원 실행 차단, 일일 보고와 수량·시간·시간대 일치, viewer/401/엄격 query/no-store/유휴 유지, 실제 알람 발생·확인·복귀와 동적 심각도·다른 수집원 격리·64KiB를 확인했다.
- medium 검토: CX-02 담당자가 독립 검토했다. 미연결 실행이 같은 ID의 작업지시 품목을 빌리는 문제를 발견하여 실제 연결 원장을 통해서만 조회하도록 수정했다. 새 기능의 별도 고위험 DB 이관은 없다.
- 기준 문서 영향: 신규 대시보드 참고 지표 범위다. 성능효율은 null이며 기존 OEE 후속 합의 조건을 변경하지 않는다.
- 브라우저 검사 영향: 새 조회 경로 추가이며 기존 요소 ID·화면·브라우저 검사 스크립트는 바꾸지 않았다. 새 화면의 실제 결합은 Claude 담당이다.
- 남은 범위·제한: 공개 Neon·Vercel 이관/배포와 UI 결합은 수행하지 않았다. 전체 기획 수락·성능 검증과 구분한다. 수집원이 여러 개인 경우 대시보드는 명시적 scope, 일일 보고 기본 경로는 라인 전체다.
