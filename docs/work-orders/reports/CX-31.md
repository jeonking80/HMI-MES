## 변경

`contracts/conflict_codes.py`에 공개 코드8개를 고정하고 typed ConflictError로 내부 진단과 공개 분류를 분리했다. 작업지시 등록/배포/연결/취소와 명령 사전 판정의409는 top-level `detail`, `reason_code`를 반환한다. 내부 예외 문구를 파싱하거나 응답에 노출하지 않는다.

코드: RESERVED_EXECUTION_NOT_SETTLED, WORK_ORDER_VERSION_CHANGED, WORK_ORDER_ALREADY_BOUND, FRESH_SOURCE_REQUIRED, PHYSICAL_EXECUTION_MISMATCH, ID_CONTENT_CONFLICT, CONTROL_VERSION_STALE, STATE_NOT_ALLOWED. 의미·호환 조건은 `contracts/HTTP_CONFLICT_CODES.md`에 기록했다.

기존 공개 detail,401/403 권한, 요청 actor/Origin/CSRF, 거절 조건과 work-order version→already-bound 판정 순서를 유지했다. preflight SnapshotNotFound도 FRESH_SOURCE_REQUIRED로 분류한다. 명령/정산·실적·미확정 요청 처리와 내부 gateway protocol은 바꾸지 않았다. UI는 Claude 담당이다.
