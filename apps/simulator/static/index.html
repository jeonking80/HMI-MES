03 / FIELD SCENARIOS

현장 모드와 시험 입력

가상 PLC에 실제 반영되는 입력

현장 / 운전 모드

모드 변경도 운전 허용 조건과 제어 버전을 바꿉니다. 원격 모드 조작은 별도 OPC 경로를 사용합니다.

안전·고장·공압·온도 시험

-50~+50°C를 측정 PV에만 더합니다. 물리 온도·히터·레시피는 바꾸지 않으며, 측정값은 0°C 아래로 내려가지 않습니다. 재시작 후에도 편차가 유지됩니다.

정지 위치 대조용 피드백 입력

가상 현장 피드백을 직접 설정합니다. 화면의 정지 확인만으로 물품 위치 검증을 대신할 수 없습니다.

04 / EXPLICIT RECOVERY

복구 확인과 재공 정리

확인 전

재시작 후 명시적 복구

저장 상태·원래 명령·안전 입력을 대조하세요. 복구 확인은 자동 START를 수행하지 않습니다.

미확정 명령은 먼저 위 항목을 대조한 뒤 중단을 확정하세요. 시간 초과만으로 실패를 단정하지 않습니다.

선택한 재공 폐기

정지·위치 확인 후 선택한 물품만 사유와 함께 폐기합니다. END_RUN은 재공을 자동 폐기하지 않습니다.

물품 위치 관측 후 선택할 수 있습니다.

FIELD PUBLICATION TEST

설비별 필드 발행 시험

OPC 연결 유지 · PLC 자체 운전 지속

로컬 PLC 관측과 별개로 선택한 설비의 OPC 발행값·생존 신호 또는 품질에 시험 조건을 적용합니다. 동결·읽기 실패·가상 필드 단절은 마지막 NORMAL 발행값과 원래 시각·생존 신호를 유지합니다. 읽기 실패·필드 단절은 실제 OPC 세션을 끊지 않습니다.

설비저장 설정 / 버전실제 발행 / 버전발행 runtime / 읽기 진행발행 품질 / 보존 원본 품질생존 신호 / 원래 시각

DELAY는 원본 값·품질·시각을 보존합니다. 첫 읽기 완료 대기와 진행 중 읽기는 실제 발행 runtime에서 확인하세요. 완료 표시는 Good 품질 판정이 아닙니다. 시간 변경은 NORMAL의 실제 발행 후 새 DELAY로 적용합니다.

현재 설정 조회 후 적용하세요. 동결·읽기 실패·필드 단절·DELAY는 NORMAL의 실제 발행 후 설정할 수 있습니다.
